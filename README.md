# Zen Browser scripts

- [page-suggest-vim-nav.user.js](./page-suggest-vim-nav.user.js): Tampermonkey script for enabling Vim-like `alt+J` `alt+K` navigation on web pages
- [zen-urlbar-vim-nav.uc.mjs](/zen-urlbar-vim-nav.uc.mjs): [fx-autoconfig](https://github.com/MrOtherGuy/fx-autoconfig) script for enabling Vim-like `alt+J` `alt+K` navigation in the browser chrome
