# Zen Browser scripts

## Tampermonkey

- [page-suggest-vim-nav.user.js](./page-suggest-vim-nav.user.js): enable Vim-like `alt+J` `alt+K` navigation on web pages

## fx-autoconfig

Install [fx-autoconfig](https://github.com/MrOtherGuy/fx-autoconfig) first. Then `cp config.mk.example config.mk`, set
your `ZEN_PROFILE_DIR` and run `sudo make install`.

- [zen-urlbar-vim-nav.uc.mjs](/zen-urlbar-vim-nav.uc.mjs): enable Vim-like `alt+J` `alt+K` navigation in the browser chrome
- [zen-split-focus-follows-mouse.uc.mjs](/zen-split-focus-follows-mouse.uc.mjs): enable focus change on mouse hover in split view
